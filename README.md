# Acompañamiento Pedagógico · 4.º año (versión de prueba)

Seis aulas, una por espacio curricular: Historia, Geografía, Matemática, Lengua y Literatura, Lengua Extranjera Inglés y Biología.

Esta versión es **solo para probar el material**: se puede avanzar sin resolver las actividades. Las versiones que se cargan en Moodle (SCORM) mantienen el bloqueo y no se generan desde acá.

Cada carpeta es un aula completa. Para volver a generarla desde un SCORM nuevo hay que aplicar el cambio de modo prueba sobre una copia, nunca sobre el original.
